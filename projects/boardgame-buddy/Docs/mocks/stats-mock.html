What changes on the hub

The four standalone tiles (Games / Plays / Buddies / Top game) collapse into one card. No count is lost: the Collection and Buddies preview cards below already print their own totals in the sub-head, and every number moves to the Stats screen in fuller form.

One tap target, not four

The whole card routes to /profile/stats. The three cells inside are display only — no nested buttons, so there's no ambiguity about what a tap does and the 44×44 rule is satisfied by the card itself.

Reuses the preview-card chrome

Same .preview-card head as Collection / Wishlist / Plays / Buddies — icon, title, sub, See all →. The stats block reads as the fifth card in that stack rather than a new species.

Wins is a new number on the hub

bgb_user_stats already returns win_count; the hub just never printed it. Plays and Top game come from the same RPC, so the hub needs no extra call.

Medal tokens

Three new CSS variables — --medal-gold, --medal-silver, --medal-bronze — warm-shifted so silver and bronze sit in the espresso/gold family instead of reading as cold grey. Each has a light-theme value that keeps the numerals legible on white.
